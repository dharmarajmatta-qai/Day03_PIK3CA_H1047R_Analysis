# Day 3: PIK3CA Protein Structure Analysis

## Objective
Explore the PIK3CA protein structure using PDB data and Python.

## Tools
- Python
- Biopython
- Pandas
- Matplotlib
- NumPy

## Files
See the project folder for available structure, graph and contact-analysis files.

## Important scientific notes
- PDB residue numbering may differ from UniProt numbering.
- Confirm the protein chain identity before interpreting results.
- Confirm the ligand chemical component ID before interpreting contacts.
- A distance-based contact list does not prove binding strength or drug efficacy.
- This is an educational computational analysis, not a clinical conclusion.

## Data source
RCSB Protein Data Bank: https://www.rcsb.org/structure/8V8H
